## 🌟 Key Features

### 📊 Advanced Trade Log & Analytics
* **Dynamic Table & Custom Views:** Order, toggle, and filter columns (P&L, Points, Strategy, Rating, Screenshots).
* **Multi-Account Support:** Seamlessly separate metrics across Evaluation, Funded, and Live accounts.
* **Smart Filter Drawer:** Filter by asset class (NQ, ES, MNQ), session (RTH, Overnight, NY, London, Asia), and outcome (Wins, Losses, Break-even).
* **Needs Attention Queue:** Quick-filter trades that are missing screenshots, strategies, or post-trade reviews.

## 🚀 Installation

### Option 1: Via BRAT (Recommended for Beta Testing)
1. Install the **BRAT** plugin in Obsidian (*Settings > Community plugins*).
2. Open BRAT settings and click **Add Beta plugin**.
3. Paste the repository URL: `https://github.com/yamihugo/Tradebook`
4. Click **Add Plugin** and enable **Tradebook** in your installed plugins list.

### Option 2: Manual Installation
1. Download the latest `main.js`, `manifest.json`, and `styles.css` from the [Releases](https://github.com/yamihugo/Tradebook/releases) page.
2. Create a folder named `tradebook` inside your vault's plugin directory:
   `.obsidian/plugins/tradebook/`
3. Paste the downloaded files inside the folder and restart/reload Obsidian.

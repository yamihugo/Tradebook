# Roadmap

**This is intent, not a promise.** Anything here can move, change or be dropped.
What has actually shipped lives in the [CHANGELOG](CHANGELOG.md).

## Small — next

- [ ] Entry/exit hour pickers (the date has a picker; time is still typed)
- [ ] Sort and group accounts by size
- [ ] Scale in/out made visible (expand fills, closed/total)
- [ ] Saved Trade Log filter views
- [ ] Keyboard navigation in the Trade Log (j/k, Enter, x)
- [ ] Drawdown widget (underwater curve)
- [ ] Rolling average widget (10/20/30/50)

## Big — later

- [ ] A first-run guide inside the plugin (today the README is the only path)
- [ ] Strategy sandbox (isolated testing)
- [ ] Strategy-specific review templates
- [ ] Broker exports beyond Tradovate
- [ ] Missed trades — setups not taken
- [ ] Help mode (inline guidance)
- [ ] Offline voice notes

## Not planned

- **MAE/MFE** — needs excursion data the journal deliberately does not collect.
- **A separate mobile app** — Obsidian already runs on mobile.
- **Prop-firm enforcement** — this is a journal, not a firm. It reports; it never imposes.
